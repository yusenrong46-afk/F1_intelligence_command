M8.5 Upgrade Explanation

M8 explained blocked rules. M8.5 helps resolve blocked rules safely by adding table lineage, legal dependency graphs, repair evaluation, reviewer workbench artifacts, multi-city stress testing, and a stronger artifact-grounded chatbot.

Executive Summary

M8.5 is an additive verification workbench on top of M8. It does not replace the deterministic verifier, and it does not allow repair, dashboard, reviewer actions, or chatbot answers to directly verify rules.

Core invariant: Extraction proposes. Retrieval finds missing context. Repair patches weak candidates. Verification proves or rejects. Dashboard explains. Chatbot analyzes. GIS consumes only verified rules.

Remaining Limitations

M8.5 is a stronger verification workbench, not an automatic legal approval engine. It improves evidence precision, review readiness, and generalization visibility, but blocked legal rules still need deterministic verification and sometimes human review.

  • Vancouver and Calgary table-derived counts are zero under the current simple parser.
  • Dependency graph artifacts identify blockers but do not yet retrieve and resolve all referenced sections.
  • Reviewer actions are modeled, but a persistent dashboard action workflow is still future work.
  • Browser-level smoke testing of each optional Streamlit page remains useful before a public demo.
