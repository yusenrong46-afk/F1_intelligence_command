# M8.5 Results

Date: 2026-07-05
Status: Checkpoint 16 cross-city repair generalization measured across Burnaby, Vancouver, Calgary, and newly fetched Surrey R3

## Summary

M8.5 is now implemented through Checkpoint 16 for Burnaby R1 and cross-city
repair stress. The current
pipeline emits table lineage, table-derived candidates, dependency graph
artifacts, repair evaluations, guarded repair-rerun attempts, verifier rerun
request records, review packets, M8.5 decisions, M8-vs-M8.5 comparison,
summary, and chatbot context. The repair layer now also produces conservative
table-proof patches from exact M7 table-cell evidence when the reviewed rule's
object, value, unit, and scope refinement are safe. The latest repair family
adds M7 matrix range normalization for dwelling-unit table cells and redundant
table-condition cleanup, then still requires deterministic verifier rerun.

M8.5 remains additive. It does not alter M7/M8 verifier behavior, does not
export review/context rules into GIS, and does not let repair or reviewer
actions directly promote rules.

The current repair generalization result is mixed: benchmarked Burnaby,
Vancouver, and Calgary preserve `false_verified_count = 0` and
`false_approval_count = 0`; the newly fetched Surrey R3 holdout runs end to end
but is marked `measured_unsafe` because no Surrey gold benchmark exists yet and
the benchmark gate labels all 38 verified rules as false verified.
